# Least-Cost Electrification Analysis for Benin
**Author:** Lilian Sudi  
**Date:** June 2026  
**Prepared for:** VIDA Case Study


## Overview
Least-cost electrification analysis for 17,205 settlements across Benin, covering:
- Electricity demand estimation over a 15-year planning horizon (2025-2040)
- LCOE-based technology comparison (grid extension, mini-grid, solar home systems)
- Sensitivity analysis across 6 cost scenarios
- Investment prioritisation scoring across all settlements


## Key Findings
| Technology | Settlements | Population |
|------------|-------------|------------|
| Grid Extension | 179 (1%) | 7.7M (54%) |
| Mini-Grid | 17,026 (99%) | 6.4M (46%) |
| Solar Home System | 0 | 0 |
Mini-grid dominance is prevalent across all 6 sensitivity scenarios tested.
